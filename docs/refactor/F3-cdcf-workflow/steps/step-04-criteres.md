# Step 04 — Criteres d'acceptation globaux

## 1. Criteres niveau projet
Definir les criteres d'acceptation **globaux** (niveau projet, pas niveau story).
Format verifiable, observable. Exemple : "Un utilisateur authentifie peut creer un
projet et le retrouver apres reconnexion."
Inscrire dans `criteres_acceptation:` (frontmatter).

## 2. Garde-fou
Chaque critere doit etre **testable**. Si un critere n'est pas verifiable, le
reformuler ou le retirer (pas de critere decoratif).
