# Step 03 — Perimetre & contraintes

## 1. Perimetre
Lister explicitement **dans le scope** et **hors scope**. Le hors-scope est aussi
important que le dans-scope (evite le scope creep cote workflow_dev).
Inscrire dans `perimetre:` (corps) du CDCF.

## 2. Contraintes
Techniques (stack imposee, versions), delais, budget, conformite. Une contrainte par
ligne dans `contraintes:` (frontmatter). Vide si aucune.
